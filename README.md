# Readme Gen

Auto-generate README.md for any project by reading its files.

![version](https://img.shields.io/badge/version-1.0.0-blue.svg)

## Tech Stack

Node.js

## Project Structure

```
readme-cli/
├── src/
│   ├── commands/
│   │   └── generate.js
│   ├── utils/
│   │   ├── detectStack.js
│   │   ├── formatReadme.js
│   │   ├── readPackageJson.js
│   │   └── scanStructure.js
│   └── generator.js
├── index.js
├── package-lock.json
├── package.json
├── README-old.md
└── README.md
```

## Installation

```bash
# 1. Clone the repository
git clone https://github.com/subhiksha1196/readme-gen.git
cd readme-gen

# 2. Install dependencies
npm install
```

## Scripts

| Script | Command |
